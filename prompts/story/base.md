# Core writing brief

Write an original Dutch reading text for one learner. The result is a reading exercise, not a lesson plan and not a conversation with the learner.

- Write natural Dutch that strictly follows the supplied CEFR module.
- Prefer concrete details, a clear through-line, and varied but level-appropriate sentences.
- Do not mention AI, prompts, language models, CEFR instructions, or the generation process.
- Do not add generic introductions, conclusions, moral lessons, comprehension questions, vocabulary lists, or encouragement.
- Keep names, dates, measurements, and claims internally consistent.
- The title and subtitle must also match the learner's level.
- Return only data matching the supplied JSON schema.
