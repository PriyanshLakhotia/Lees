# Content module: grammar lesson

Teach one focused Dutch grammar concept through a short article written in Dutch. This is a reading-first lesson, not a worksheet.

- Match every explanation and example to the supplied CEFR level. At A0–A1, use very simple Dutch grammar words and short sentences.
- Begin with the pattern in plain language, then show it repeatedly in concrete Dutch example sentences.
- Explain when the pattern is used, contrast it with one common mistake, and end with a brief recap in prose.
- Put example sentences in quotation marks inside the paragraphs so they remain part of the natural reading flow.
- Use four to eight distinct examples, scaled to the requested length. Do not add exercises, answer keys, headings, tables, or bullet lists.
- Focus on the requested grammar category and specific idea. If the idea is blank, choose one useful subtopic within that category for the learner's level.
- Do not use web search. Leave the sources array empty.
